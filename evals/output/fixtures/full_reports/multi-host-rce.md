排查以云安全中心的两条告警为起点：01:06 对 gateway01 的异常进程告警（告警 Id 920001）和 01:10 对 worker02 的异常脚本告警（告警 Id 920002）。两台主机的排查依据是进程启动、文件访问、登录和网络外联记录，并结合 WAF、访问日志与操作审计还原链路。下面按主机分别说明，再给出跨主机关联的依据。

#### gateway01：模板注入入口与令牌读取

WAF 在 01:05:12 命中模板注入规则，来源为 203.0.113[.]88；访问日志在同一时刻记录了对应的 POST 请求。网关是客户自研组件，没有对应的 CVE，这次注入属于服务端模板注入，修复需由业务方修改代码。

![](IR-20260724-gateway01-multi2-rce-920001.assets/TODO-gateway01-waf-hit.png){caption="图 1 | WAF 模板注入命中记录（gateway01）"}

进程启动记录显示，01:05:14 网关进程启动了 shell（`gateway -> sh`）；同一秒的文件访问记录中，主体 `sh` 读取了 `/etc/automation/token`。注入请求与 shell 启动相隔两秒，shell 启动的同一秒就读取令牌，这说明攻击者通过模板注入取得了命令执行能力，并读取了未加密保存的自动化账号令牌。

网络外联、远程和数据库登录记录中未观察到其他异常，主机上未发现恶意文件、cron、systemd 或 rc.local 持久化项，系统关键文件未见篡改。

> gateway01 的网络外联、进程启动、登录记录和云安全中心告警覆盖 2026/07/20 起至调查时，操作审计覆盖 2026/07/01 起至调查时。WAF 只保留命中规则的请求，01:05 之前攻击者是否做过探测没有日志可查。

#### worker02：自动化账号下发命令与脚本执行

操作审计记录显示，01:09:33 调用者 automation-runner 经云助手向 worker02 实例下发命令。三秒后的进程启动记录中，云助手进程启动 shell 执行下载，下载的文件为 `/tmp/diag.sh`（sha256 demo-cccc3333）；从 01:10:02 起，shell 陆续执行系统与网络信息收集命令。三步在时间上紧接，进程链从云助手进程到 shell 没有中断，因此 worker02 上的执行行为可以确认来自这次云助手调用。

![](IR-20260724-gateway01-multi2-rce-920001.assets/TODO-worker02-process-chain.png){caption="图 2 | worker02 云助手到 shell 的进程链记录"}

登录记录中未观察到交互式登录，worker02 上的命令均由自动化账号经云助手下发执行。网络外联仅观察到脚本下载连接，未发现 cron、systemd 或 rc.local 持久化项；`/tmp/diag.sh` 仍在已隔离的主机上，系统完整性等待镜像重建后恢复。

> worker02 的网络外联、进程启动、登录记录和云安全中心告警覆盖 2026/07/20 起至调查时，操作审计覆盖 2026/07/01 起至调查时。脚本执行时未启用文件访问审计，脚本读取了哪些文件没有记录可查，要判断它是否触及业务数据需要补充该时段的文件访问记录。

#### 跨主机关联分析

两台主机的关联依据是操作审计。记录中的调用账号 automation-runner 正是 gateway01 上被读取的令牌所属账号，调用时间 01:09:33 在令牌被读取后约四分钟，命令目标为 worker02，操作审计也将这次调用与攻击源 203.0.113[.]88 关联起来。worker02 的进程链在命令下发三秒后启动，与调用记录一一对应。这几条记录在账号、时间和目标上相互衔接，足以确认 worker02 上的命令来自 gateway01 泄露的自动化令牌，两台主机属于同一起事件，worker02 本身没有被直接利用的漏洞。

## 总结与安全建议 / Summary & Advisory

### 事件总结 / Event Summary

这是一起由公网网关模板注入引发的远程代码执行，攻击者借网关进程读到的自动化账号令牌把命令送进内部节点 worker02，两台主机目前都已完成止损，网关漏洞修复和 worker02 镜像重建仍在进行。事件暴露的控制缺口有两处：自研网关存在服务端模板注入漏洞，自动化令牌以未加密文件形式放在公网入口主机上，而且拿到令牌就能向内部节点下发命令。客户下一项最高优先级工作是把网关修复上线、完成 worker02 重建，并在此之前完成同类网关实例和任务节点的复查。
