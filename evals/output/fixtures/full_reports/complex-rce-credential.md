入口定位在对外 API 接口上。访问日志记录到 `203.0.113[.]77 - - [22/Jul/2026:02:14:08 +0800] "POST /api/export HTTP/1.1" 500`，请求参数中带有 shell 元字符；两秒后的进程启动记录显示业务进程 `java` 派生出 `sh`。请求时间、来源与进程派生时间能够对应，可确认攻击者是通过 `/api/export` 接口的命令注入取得主机命令执行能力，HTTP 500 不能否定进程记录所支持的命令执行事实。

凭据暴露发生在两分钟后。文件访问记录显示，02:16:31 由同一进程树下的 `sh` 读取了 `/opt/app/.env`，该文件保存业务使用的云凭据。读取主体与前一步的执行链一致，因此这批凭据应按已泄露处置。

### 事件总结 / Event Summary

本次事件确认为公网 API 命令注入引发的远程代码执行，攻击者在主机上取得命令执行能力、读取业务云凭据并写入计划任务；公网入口和计划任务已处置完毕，主机重建与凭据轮转仍在进行。根因是对外接口对用户输入未做有效过滤，加之云凭据以明文保存在业务配置文件中，一次接口利用就直接带来了凭据暴露。客户下一步的最高优先级是完成旧凭据的全量吊销，并调取对应账号的操作审计，判断凭据在轮转前是否已被使用。

reason :: Web 应用防火墙可在接口前置拦截带 shell 元字符的注入请求，并在代码修复验证完成前提供缓冲。
