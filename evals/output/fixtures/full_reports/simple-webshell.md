事件定性 :: 攻击者利用 web01 自研上传接口的任意文件上传漏洞，写入了 PHP Webshell（放在网站目录中、可通过网页远程执行命令的后门文件）。写入一分多钟后，主机上的 Web 服务进程执行了系统命令，很可能是攻击者借 Webshell 所为。事件定为高危。
影响范围 :: 已确认影响 web01 一台主机：网站目录被写入 Webshell，Web 服务进程执行了查看运行身份的命令。攻击者是否登录过主机、是否波及其他主机，目前无法确认，明细见「影响评估」。
处置状态 :: 尚未止损。上传接口隔离、攻击地址封禁、Webshell 清除和接口修复都还没有开始，同类资产复核和日志补齐也未开展。
残留风险 :: Webshell 仍在网站目录中，清除之前攻击者可随时再次访问并执行命令。上传接口漏洞未修复，攻击者可以重新写入后门。主机登录记录缺失，攻击者是否登录过主机尚无法确认。

排查从云安全中心的「Webshell 通信」告警（ID 900001）开始。响应人员通过只读远程取证，调取了 web01 的访问日志和云安全中心进程启动记录，并检查了主机上的计划任务、启动项、账户和系统文件完整性。

> 访问日志经日志服务采集，从 2026/04/10 起可查，更早的日志已轮转，上传接口在此之前是否已被利用无法确认。进程启动记录和云安全中心告警从 2026/04/12 起可查。

访问日志显示，2026/04/17 18:12 至 18:17，来源 203.0.113[.]45 向 `/upload/` 接口连续发起 9 次 POST 请求，每次变换文件名后缀，均返回 400。18:18，同一来源的请求返回 200：

```text
203.0.113[.]45 - - [17/Apr/2026:18:18:12 +0800] "POST /upload/x.php HTTP/1.1" 200
```

`/var/www/upload/x.php` 的修改时间为 2026/04/17 18:18:12，与这条请求一致。由此可以确认，攻击者利用自研上传接口的任意文件上传漏洞，把 PHP Webshell 写进了网站上传目录。

云安全中心的进程启动记录显示，2026/04/17 18:19:40，Web 服务进程 `php-fpm` 派生出异常的 `sh` 子进程，依次执行 `sh -c "id"` 和 `sh -c "whoami"`，这两条命令用于查看当前运行身份。命令出现在 Webshell 写入后约一分半钟，攻击者很可能是通过 Webshell 下发了这些命令。现有记录缺少完整的命令回显，这一点目前还不能确认。

在进程启动记录覆盖期内，未观察到可疑的外联连接。主机上未观察到可疑的计划任务、systemd 服务或 rc.local 启动项，也没有发现新增或异常账户；`rpm -Va` 校验未发现关键系统文件被篡改。

这起事件源于 web01 自研上传接口的任意文件上传漏洞，攻击者借此写入 Webshell，很可能随即执行了系统命令。云安全中心在 Webshell 写入约两分钟后发出告警，但目前仍未止损，Webshell 和漏洞都还在。

下一步最优先的是隔离上传接口、删除 Webshell 并修复漏洞，随后复核部署同一接口的其他资产。建议延长 web01 访问日志的保留时间，以便追溯更早的上传活动。

::: recommendation priority=P1 type=product
name :: Agentic BAS 智能渗透验证
risk :: 上传接口修复和上传目录加固是否真正生效，缺少从攻击视角验证的客观证据。
reason :: Agentic BAS 由大模型驱动规划、渗透、验证与报告智能体，可还原攻击链、验证漏洞可利用性，并输出可复现的请求轨迹与验证报告。
action :: 以 web01 上传接口及其他对外文件上传功能为范围发起验证任务，确认无法再上传可执行脚本后纳入周期性复测。
:::

::: recommendation priority=P1 type=product
name :: 云安全中心
risk :: web01 的登录维度缺少日志，告警发出后 Webshell 仍留在主机上。
reason :: 云安全中心已在 web01 上发现 Webshell 并记录进程启动，补开登录日志采集后可覆盖登录维度，告警处置流程也能缩短止损时间。
action :: 为 web01 等对外 Web 主机开通登录日志采集，并为 Webshell 类告警明确处置责任人和响应时限。
:::

::: recommendation priority=P2 type=product
name :: Web 应用防火墙

reason :: Web 应用防火墙可在请求到达业务服务器前检测并拦截 Webshell 上传等常见 Web 攻击。
action :: 将 web01 的对外业务接入 Web 应用防火墙，并针对 `/upload/` 接口启用文件上传防护规则。
