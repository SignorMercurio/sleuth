# Runtime Governance

- Treat `evals/runtime/` as deterministic regression for the mock SIREN engine,
  scenario data, fault handling, and transcript checker. Passing it does not
  prove that an agent reaches the correct conclusion; use the manual drill in
  `evals/runtime/README.md` for model-behavior review.
- `evals/runtime/mock_siren/policy.py` and the mock server tool definitions are
  snapshots of the real SIREN contract. When that contract changes, compare the
  upstream behavior and update the snapshot and its tests together.
- `scripts/permission_probe_anchors.yaml` owns the semantic anchors checked in
  `agents/interface.yaml`, `agents/openai.yaml`, and `SKILL.md`. Preserve the
  safety behavior and update the anchors with any intentional wording change.
- `reports/trust_report.json` and `reports/trust_report.md` are generated by
  `scripts/gen_trust_report.py`. Do not hand-edit them. After changing a scanned
  repository file, dependency, script surface, or `skills/sleuth/`, regenerate
  the reports and then run the generator with `--check`.
- Keep repository-check dependencies exactly pinned in `requirements.txt` and
  install them with `python3 -m pip install -r requirements.txt`.
