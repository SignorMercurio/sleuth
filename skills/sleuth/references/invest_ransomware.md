# 勒索软件调查指南

## 调查重点（只读检查项）

1. **确认勒索进程**：定位异常高资源进程及其父进程/启动时间。
2. **加密行为**：**`find -mmin -60`** 找正在被改写的文件窗口；勒索信文件名常含 **`*README*`、`*DECRYPT*`、`*RANSOM*`**，读其内容取勒索渠道/钱包地址。
3. **追溯入口**：看进程启动链与父进程；查下载目录/临时目录的近期落地物。
4. **影响范围**：按加密扩展名统计受影响文件数与目录。

## 云端日志补充

主机被加密后本地证据可能不可靠；按 `references/cloud_log_queries.md`「挖矿 / 可疑进程 / RCE 后续执行」和「反弹 Shell / C2 / 数据外传」用 SAS 进程与网络遥测还原加密进程父链及 C2、密钥或勒索服务器外联。

## ATT&CK 映射
- **T1486** - 数据加密以造成影响
- **T1490** - 抑制恢复
- **T1529** - 系统关闭/重启（可能）
