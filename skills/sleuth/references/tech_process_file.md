# 进程和文件分析技巧

## 进程关联（非显然的 pivot）

- **`/proc/<PID>/` 反查归属**：`cwd` 推测进程所属业务（如 `/opt/rocketmq`→RocketMQ），`exe` 取真实可执行路径，`environ` 看启动环境；某进程 fd 指向另一进程 → 两者关联。
- **systemd 关联**：`systemctl status <PID>` 不止给服务名，**CGroup 字段会列出该服务的所有兄弟/子进程**，是发现关联进程的捷径；再 `journalctl -u <service>` 限时间窗看日志。
- **网络/进程树**：按远程 IP:端口反查进程，按父进程链向上追溯到拉起者。

## 文件时间分析（判读规则）

- **时间戳判读**：`ctime` 是 inode 元数据变更时间，不是创建时间；权限/属主调整、部署和恢复也会令其变新。`mtime` 很早而 `ctime` 很新只是回改时间戳的候选线索，要结合日志、文件内容与正常变更记录核验。
- **命令是否被替换**：看系统命令（如 `/usr/bin/ps`）的 `ctime` 是否接近告警时间。
- **发现同期文件**：先限定恶意文件所在目录与相关业务路径，按已核对的事件时间窗分别筛 mtime 与 ctime，再合并去重。GNU find 的 `-newermt '<起点>'` 只筛 mtime，ctime 用 `-newerct '<起点>'`；按需加对应终点，不支持该谓词时列候选文件元数据后过滤。不要只按 mtime 排除近期变动，否则会漏掉时间戳被回改的文件；命中后再核验内容和因果关系，不把时间相邻写成同源。

> Windows 取文件时间：`Get-Item <文件> | Format-List *Time*`。
