# 风格语料目录

存放作者手写的文章 / 报告样本，供步骤 8 写报告时参照文风；读取规则见 `references/report_style.md`「风格语料的使用」。

- 本目录是 skill 的正式资源并纳入 Git；只提交可以随 skill 分发的脱敏样本。
- `curated-ir-excerpts.md` 是首选样本：只放经过筛选、完全脱敏或重新组合为合成事实的应急响应报告片段。
- 不要复制真实客户报告、原始日志、IoC、账号或资产信息；历史材料只用于蒸馏表达方式。
- 其他 Markdown / 纯文本只在首选样本不存在时使用；过长的博客或教程应节选核心章节，且不能覆盖报告文体。
